
# تشغيل محاضرة Streamlit الأولى

هذه الملفات تشغّل محاضرة **مقدمة في الذكاء الاصطناعي** كتطبيق تعليمي تفاعلي.

## 1) المتطلبات
يجب أن يكون Python مثبتًا على الحاسوب.

## 2) تثبيت المكتبات
افتحي Terminal / Command Prompt داخل مجلد المشروع واكتبي:

```bash
pip install -r requirements.txt
```

## 3) تشغيل المحاضرة
اكتبي:

```bash
streamlit run app.py
```

سيفتح التطبيق تلقائيًا في المتصفح.

## محتوى التطبيق
- مقدمة وأهداف تعلم
- رسوم توضيحية تفاعلية مبسطة
- الفرق بين النظام التقليدي وAI
- AI / ML / DL
- تطبيقات في علوم التسيير
- تحليل البيانات واتخاذ القرار
- دراسة حالة Customer Churn
- Quiz تفاعلي
- نشاط TD
- المراجع

## ملاحظة
لا يحتاج الطالب إلى تثبيت Streamlit إذا تم نشر التطبيق لاحقًا على الإنترنت؛ يكفيه رابط الويب.
